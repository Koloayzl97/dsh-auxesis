# dsh-auxesis — 能力增益

Auxesis（αὔξησις，增益）：不抢正向解题的位置，只在**答错会返工**的那一步借一路更强的推理，并把借来的东西沉淀成自己的。

## 两个工具 / 一个开关

- **`auxesis`（模型工具）**：给定一个自包含的难题，从目标反推必要前提、找出卡住最多下游的瓶颈、给最短正向路径，并附 `decision`（一句话结论）与 `extend`（最多 3 条顺带建议）。只回结构化 JSON（`target / success_check / preconditions / chain / crux / decision / plan / extend / assumptions / missing / confidence`），中间不把会话历史带过去。`want=steps` 时换成构造器提示，产出 1–5 个带 `expect` / `if_fails` 的构造；`auxesis_steps` 已并入，不再单独注册。
- **`auxesis_investigate`（模型工具）**：答案是散在文件/日志里时用它。它可以要求宿主去 `read / tail / grep / list`，拿到材料再作答，最多 3 次；也可以带图片（`images`）。取数只读、限定在 `settings.roots` 内、拒凭据类文件名与符号链接。原始材料不会进调用方的上下文。
- **自动决策开关（发送栏）**：发送栏上那枚「自动决策」pill，开/关即时写盘、下一轮系统提示即生效，不用重载。开着时可逆的决策（选型、取舍、优先级）不再问用户，模型直接调 `auxesis` 拿结论并执行；不可逆动作、偏好与凭据、以及 `confidence<0.5` 或 `missing` 非空的判断仍然问人。
- **设置页（插件 → Auxesis · 能力增益）**：列出本机所有已配置 provider/model，勾选允许被用的路由，指定默认路由、推理强度、输出预算与超时；带搜索框（模型多时按 id 或名字过滤）。
- **触发与沉淀**：系统提示里有一段 order 10 的判断闸门（错一步会不会返工）；`auxesis` 成功时抽瓶颈模式卡，`auxesis_steps` 成功时抽套路卡（目标 → 常用首步），注入后续对话。

## 触发设计

早期版本按任务类型列清单（估算/排期/选型…），结果是模型对号入座、清单外一律不调。现在只留一个信号：**这个结论如果错了，会不会要我返工**；会就先用，不会就直接做，拿不准按“会返工”处理。

提示词段放在 order 10——紧跟开场白与 persona，排在 plan/team/工具指导（500 起）之前，是模型读到的第一段实质指令。

## 经验沉淀

`~/.dsh/dsh-auxesis/patterns.json` 保存每次成功逆向抽出的卡：`目标形态 → 瓶颈类型 → 第一步`，同一模式重复出现会累加计数。写入有质量门槛（目标/瓶颈过短或同义复述不记），注入前按瓶颈去重、只取最近 5 条不同瓶颈，并注明“只作提示、别照搬”。截断或解析失败的调用不记录。`playbooks.json` 同理：只记首步的第一条非空行（多行命令不会被截成半截），按目标去重取最近 3 条。

这不是让模型变聪明，是让它别忘——插件碰不到权重，能碰到的是上下文。

## 事件日志

`~/.dsh/dsh-auxesis/events.jsonl` 每次调用追加一行：`tool / want / route / elapsedMs / rounds / fetches / autoDecide / ok / kind / confidence / missing / crux / phase`。路由失败也会记（`kind` 就是错误类别），超过 2MB 滚一份 `events.1.jsonl`。写失败静默，绝不影响调用。

```bash
npm run summary        # 或 node scripts/summary.mjs
```

按工具、结果、自动决策开关分组，给出低置信（<0.5）、取数耗尽、最近 10 条。这份数据拿来回答三件事：触发正例到底有没有、开关有没有减少询问、同类失败是否重复——不靠感觉。

## 边界

- 只接受被勾选的路由：`route` 不在列表里会报错并列出可用项；省略时用默认路由。
- 备选路由只支持 **单条**：设置页单选、`/select` 整串校验、`routePlan` 不再拆逗号多条。
- 每次请求有硬预算（默认 16384 输出 token / 180 秒），超时与截断都会在结果标记里写明。
- 不执行代码、不读文件、不联网；数值结论仍需在宿主侧复算。
- 折叠行的标题仍是 `工具调用 · auxesis`，DSH 通用卡片如此；展开后第一行是 `⟦Auxesis⟧ · 路由 · 耗时 · 完整/已截断`。

## 安装

`插件 → 添加插件` 指向本目录，或 `plugin_manager install_bundle` 使用绝对路径。插件零依赖（只 import `node:` 内置模块），因此链接安装即可工作。
